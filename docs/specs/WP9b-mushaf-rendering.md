## الهدف

مكوّن `MushafPage` يعرض أي صفحة من الـ604 **بشكل يوازي المصحف المطبوع**، مع بنية كلمات قابلة للتظليل (استعداداً للتتبع الصوتي في WP9c)، مدمجاً في مكانين: صفحة تصفح مستقلة، ولوحة داخل شاشة الجلسة الحية.

## 1. المكوّن `frontend/src/mushaf/MushafPage.tsx`

- **الخط**: تحميل خط الصفحة `fonts/qpc-v2/p{N}.woff2` ديناميكياً عبر FontFace API مع كاش (لا تحمّل خطاً مرتين)، وجلب مسبق (prefetch) لخطي الصفحتين المجاورتين. أثناء التحميل: هيكل انتظار هادئ (لا وميض نص بخط بديل أبداً — القرآن لا يُعرض بغير خطه: `font-display` block عبر الانتظار البرمجي قبل الإظهار).
- **الأسطر**: 15 سطراً (أو 8 للصفحتين 1-2) بارتفاعات متساوية تملأ إطار الصفحة. سطر الآيات: الكلمات spans متجاورة RTL في سطر واحد **موزعة بمحاذاة الطرفين** (الكلمة الأولى تلامس يمين السطر والأخيرة يساره — flex space-between مع سطر المفرد المتمركز) — قارن بصرياً بالمصحف المطبوع واضبط. سطر اسم السورة: شريط زخرفي رصين (إطار رفيع بحد ذهبي `--dhahab` — الموضع الزخرفي المشروع هنا لأنه يحاكي زخرفة المصحف نفسه) والاسم بخط الصفحة. سطر البسملة: متمركز بخط الصفحة.
- **الكلمات**: كل كلمة span تحمل `data-surah/ayah/word` وخصائص تظليل عبر props:
  ```ts
  highlight?: { surah, ayah, word?: number } // آية كاملة أو كلمة بعينها
  ```
  التظليل: خلفية `--lazward-100` للآية الجارية وخلفية أوضح (lazward-100 كاملة الشفافية + حد سفلي `--dhahab`) للكلمة الجارية — انتقال سلس ≤150ms (يُعطَّل مع reduced-motion). النقر على كلمة يستدعي `onWordClick?` (سيلزم لاحقاً).
- **الإطار**: الصفحة على سطح `--waraq-raised` بحد `--khatt` وزوايا card، ورقم الصفحة أسفلها بخط mono، واسم السورة/الجزء أعلى الإطار بخط 13 hibr-2. النص أسود الحبر دائماً على الورق — حتى داخل عالم اللازورد تبقى صفحة المصحف ورقية (لا نعكس ألوان القرآن أبداً).
- الأداء: تخزين استجابات الصفحات في react-query (staleTime لا نهائي — بيانات ثابتة)، والتنقل السريع لا يعيد الجلب.

## 2. صفحة التصفح `/mushaf`

- متاحة للطاقم **وللطالب** (أضفها لتنقل الطالب باسم «المصحف» بجانب «صفحتي»؛ وللطاقم في الشريط الجانبي).
- تنقل: أسهم سابق/تالي (بالاتجاه الصحيح RTL: التالي جهة اليسار)، إدخال رقم صفحة، وقفز «إلى موضع»: Select سورة + رقم آية → `page-for`. مفاتيح لوحة المفاتيح (أسهم يمين/يسار) والسحب باللمس على الموبايل.
- تذكّر آخر صفحة (localStorage — مقبول هنا كتفضيل جهاز).
- موبايل 390px: الصفحة تملأ العرض بهوامش صغيرة وتبقى مقروءة.

## 3. الدمج في شاشة الجلسة الحية

- زر «المصحف» في شاشة `/sessions/live` يفتح/يغلق لوحة المصحف (على الشاشات الواسعة: عمود جانبي بجانب عناصر الجلسة؛ على الموبايل: تتوسع فوق منطقة الأزرار مع بقاء المؤقت وزر الملاحظة السريع في متناول اليد — صمم بعناية، هذه شاشة اللمس الأساسية).
- عند الفتح: تبدأ من صفحة بداية نطاق الجلسة (`page-for`) إن وُجد نطاق، وإلا آخر صفحة متصفَّحة. تنقل يدوي كامل داخلها.
- **خطاف التتبع (لـ WP9c)**: صدّر من المكوّن آلية تحكم برمجية (ref/context) `mushafControl: { goToPage(n), highlight(pos), clearHighlight() }` — الحزمة القادمة ستحركها من خدمة التعرف. الآن اربطها فقط بأزرار dev في `/dev/mushaf` القديم؟ لا — استبدل `/dev/mushaf/:page` بنسخة تستخدم MushafPage النهائي مع أزرار تجريب التظليل (آية/كلمة عشوائية) للتحقق.
- **حفظ موضع الجلسة**: عند إغلاق الجلسة لا شيء يتغير في بياناتها (التتبع لاحقاً). لا تربط المصحف بأي كتابة على الخادم في هذه الحزمة.
