## الهدف

تحويل وثيقة الاتجاه البصري `docs/design/DIRECTION.md` (اقرأها كاملة أولاً — ملزمة حرفياً) إلى: Design tokens مطبقة في Tailwind v4، خطوط مستضافة ذاتياً، مكتبة مكونات أساسية، هيكل التطبيق (Shell) بالشريط الجانبي، صفحة دخول بالهوية النهائية، وصفحة معرض مكونات للمراجعة.

## قيود صارمة

1. لا مكتبات UI (لا shadcn/Radix/MUI/HeadlessUI/أيقونات جاهزة). المكونات تُبنى يدوياً. الأيقونات: SVG inline ترسمها بنفسك بأسلوب stroke موحد (1.5px) — فقط الأيقونات المطلوبة أدناه.
2. لا تعديل على `docs/` ولا على أي ملف backend — باستثناء إصلاح واحد مطلوب في `frontend/src/api/client.ts` (أدناه).
3. كل قيمة لون/خط/مسافة تُشتق من الـ tokens — ممنوع أي hex literal داخل المكونات.
4. راجع قائمة «الممنوعات» في DIRECTION.md قبل البدء وبعد الانتهاء.

## المهمة 0 — إصلاح client.ts

في `request()`: الـ spread `...options` يأتي بعد `headers` فيستبدل كائن الـ headers المدموج إذا مرر المستدعي headers مخصصة. أصلح الدمج بحيث تُدمج options أولاً ثم تُبنى headers النهائية فوقها.

## المهمة 1 — الخطوط (self-hosted)

- ثبّت عبر npm (داخل الحاوية): `@fontsource/amiri` (وزن 700 فقط)، `@fontsource/ibm-plex-sans-arabic` (أوزان 400/500/600)، `@fontsource/ibm-plex-mono` (وزن 500).
- استوردها في نقطة دخول CSS. لا اتصال بـ Google Fonts CDN إطلاقاً.
- عرّف: `--font-display: 'Amiri', serif` — `--font-ui: 'IBM Plex Sans Arabic', system-ui, sans-serif` — `--font-time: 'IBM Plex Mono', monospace`.
- خط القرآن (KFGQPC) مؤجل لحزمة لاحقة — لا تعرض أي نص قرآني الآن.

## المهمة 2 — Tokens في Tailwind v4

طبّق كتلة الألوان من DIRECTION.md §2 حرفياً كـ CSS variables في `:root` + اربطها في `@theme` ليستعملها Tailwind (`bg-waraq`, `text-hibr`, `border-khatt`, `bg-lazward-700`, …). أضف:
- سلم الخط: 13/15/17/21/27/34 (`--text-sm` … `--text-3xl`، الأساس 15).
- الحواف: `--radius-card: 8px`, `--radius-control: 6px`.
- الظل الوحيد المسموح: `--shadow-float: 0 4px 16px rgb(20 28 63 / 0.10)` (للعناصر العائمة فقط: Modal, Toast, قوائم منسدلة).
- حلقة التركيز: outline بلون `--lazward-700` بسماكة 2px وإزاحة 2px — على كل عنصر تفاعلي.

## المهمة 3 — المكونات (في `frontend/src/ui/`)

كل مكون: TypeScript + props واضحة، RTL سليم، حالات hover/focus/disabled، تعليق موجز فوق الملف يشرح دوره. المطلوب:

1. **Button**: أنواع `primary` (خلفية lazward-700، نص nur)، `secondary` (حد khatt، نص hibr)، `ghost`، `danger` (نص khata-hifz، خلفية شفافة — الحذف ليس زراً أحمر صارخاً). أحجام md/sm. حالة loading بمؤشر دوران صغير.
2. **TextField / PasswordField / TextArea**: label فوق الحقل (وزن 500)، مساعدة وخطأ تحته بالأحمر الدلالي، حد 1px khatt يتحول lazward-700 عند التركيز.
3. **Select** (native مغلف بستايل موحد وسهم SVG باتجاه RTL صحيح).
4. **Card**: سطح waraq-raised، حد khatt، radius-card، padding 20px. بلا ظل.
5. **Table**: صفوف بخط فاصل khatt، ترويسة بنص hibr-2 حجم 13 وزن 600، صف hover بخلفية lazward-100 بشفافية 40%، أرقام tabular-nums. تدعم حالة فارغة (تستقبل EmptyState).
6. **Modal**: طبقة تعتيم `rgb(20 28 63 / 0.45)`، لوحة بعرض أقصى 480px، عنوان بخط UI وزن 600 (ليس Amiri)، أزرار في ذيلها، إغلاق بـ Esc وبالنقر خارجها، حبس تركيز بسيط.
7. **Toast**: أعلى يسار الشاشة (نهاية RTL)، نجاح/خطأ، يختفي بعد 4 ثوانٍ، بلا حركة عند reduced-motion.
8. **Badge**: شارة صغيرة بلون دلالي (تُستخدم لاحقاً للأدوار وتصنيفات الأخطاء) — variants: neutral/sahih/hifz/tajwid/dabt/waqf.
9. **AyahChip**: رقاقة الموضع القرآني (سورة: آية) — شكل حبة دائري الأطراف بحد ذهبي رفيع 1px وخلفية شفافة، النص بحجم 13. هذا الموضع الزخرفي الوحيد.
10. **EmptyState**: أيقونة SVG خفيفة + جملة دعوة للفعل + زر اختياري.
11. **PageHeader**: عنوان الصفحة بخط Amiri حجم 27 + وصف اختياري بحجم 13 لون hibr-2 + منطقة أزرار في الطرف المقابل.
12. **Spinner**: دائرة SVG بسيطة تدور، تتوقف عند reduced-motion (تتحول لثلاث نقاط ثابتة متدرجة الشفافية).

## المهمة 4 — هيكل التطبيق (AppShell)

- شريط جانبي على **اليمين**، عرض 232px، خلفية waraq-raised بحد يسار khatt. الشعار أعلى: كلمة «OLS» بخط Amiri 21 + تحتها «منصة التسميع» بحجم 13 لون hibr-2. (الاسم مؤقت — سيُستبدل لاحقاً).
- بنود التنقل (أيقونة + نص، العنصر النشط: خلفية lazward-100 وشريط بداية 3px بلون lazward-700): لوحة التحكم، الطلاب، الحلقات، الجلسات، الإعدادات. كلها تقود لصفحات placeholder فيها PageHeader + EmptyState «هذا القسم قيد الإنشاء».
- أسفل الشريط: اسم المستخدم + دوره بالعربية + زر «تسجيل الخروج» ghost.
- على الشاشات < 900px: الشريط يصبح قابلاً للطي (زر همبرغر في ترويسة علوية بسيطة). حتى 360px يبقى كل شيء صالحاً للاستخدام.
