## السياق — أهم شاشة في المنتج

هذه هي اللحظة المقدسة التي صُمم لها كل شيء: المعلم يختار الطالب، يضغط «ابدأ التسميع»، والتطبيق يسجل فوراً ويتيح تدوين ملاحظات مربوطة باللحظة الزمنية **لحظة الضغط على زر التصنيف** (وليس لحظة إتمام الكتابة) — `captureTimestamp()` تُستدعى في نفس معالج نقرة الزر، قبل أي شيء آخر.

## الواجهات الخلفية الجاهزة

- `GET /api/quran/surahs` — قائمة السور (رقم، اسم، عدد آيات).
- `GET /api/taxonomy` — الشجرة (فئات بلون token + أنواع فرعية + حقول مخصصة).
- `POST /api/sessions` `{student_id, session_type, attendance?, range_start_surah?...}` → جلسة recording. (409 لو للمعلم جلسة جارية.)
- `GET /api/sessions/active` → `{id, student..., uploaded: {"0":[0,1,...]}}` أو 404.
- `POST /api/sessions/{id}/notes` `{timestamp_ms, category_id, subtype_id?, severity?, correction_mode?, surah?, ayah?, text?, extra?}`.
- المحرك يتولى: chunks/finalize/cancel — لا تنادِ هذه المسارات مباشرة أبداً.
- `GET /api/sessions` (فلاتر student_id/group_id/session_type/from/to + ترقيم limit/offset) و`GET /api/sessions/{id}` و`PATCH /api/sessions/{id}` (grade/summary/attendance).

## الصفحات

### 1. `/sessions` — سجل الجلسات (عالم الورق العادي)
- زر أساسي بارز «بدء جلسة تسميع» → Modal الإعداد: اختيار الطالب (بحث)، نوع الجلسة (ثلاث بطاقات اختيار: سبق — درس جديد / سبقيات — مراجعة قريبة / مراجعة كبرى)، النطاق اختياري (من سورة+آية إلى سورة+آية — Select للسورة وحقل رقم للآية بحدود عدد آيات السورة)، ثم «ابدأ التسميع» → POST ثم انتقال لـ`/sessions/live`.
- إن وُجدت جلسة نشطة (`/api/sessions/active`): بدل الزر يظهر تنبيه «لديك جلسة جارية مع {الطالب}» بزري «استئناف» / «إلغاء الجلسة».
- جدول الجلسات: التاريخ (هجري+ميلادي — استخدم `lib/date.ts`)، الطالب، النوع (Badge)، النطاق (AyahChip من-إلى إن وُجد)، عدد الملاحظات، الدرجة، الحالة. فلاتر أعلى الجدول: طالب، نوع، فترة. النقر → `/sessions/{id}` (صفحة تفاصيل مبدئية: بيانات الجلسة + قائمة الملاحظات مرتبة زمنياً بطوابعها `mm:ss` بخط mono — المشغّل الصوتي الكامل حزمة لاحقة، ضع مكانه EmptyState «المشغّل قيد الإنشاء» إن لم يتوفر وقت، أو `<audio>` بسيط src=`/api/sessions/{id}/audio` كحد أدنى).

### 2. `/sessions/live` — عالم اللازورد (ملء الشاشة، بلا AppShell)
تخطيط (موبايل-أولاً — تُستخدم غالباً على جوال/تابلت بيد واحدة):
- خلفية `lazward-900` كاملة. النصوص بـ`nur`.
- أعلى: اسم الطالب (Amiri، 27) + سطر صغير: نوع الجلسة + النطاق (AyahChip بحدها الذهبي — تبرز جميلة على اللازورد).
- المركز البصري: **مؤقت الجلسة** `mm:ss` كبير (خط mono، 34+) وحوله **حلقة النبض الذهبية**: دائرة بحد `dhahab-bright` يتنفس قطرها/شفافيتها مع `level` من الـ hook (تحويل سلس، `transition` قصيرة) — عند `prefers-reduced-motion` تثبت الحلقة وتتغير الشفافية فقط.
- تحت المؤقت: شريط حالة الرفع الصغير: «الرفع مستمر ✓» / «انقطع الاتصال — تتم إعادة المحاولة» (uploadStalled) / «بقي {n} مقطعاً» عند الإنهاء.
- **شبكة أزرار الملاحظات السريعة**: زر لكل فئة نشطة من التصنيف، بلون فئته (خلفية اللون بشفافية 15% + حد باللون + النص به — فوق اللازورد الداكن استخدم نسخاً فاتحة مقروءة: طبّق اللون على النص/الحد واجعل الخلفية `lazward-800`). أهداف لمس ≥56px هنا (أهم أزرار في التطبيق). الضغط: (1) `captureTimestamp()` فوراً، (2) تفتح **لوحة سفلية** (bottom sheet منزلقة) فيها: الطابع المُلتقط ظاهراً `mm:ss` بخط mono، رقاقات الأنواع الفرعية للفئة (اختيار واحد اختياري)، صف «طريقة التصحيح»: تدارك ذاتي / تنبيه / تلقين (افتراضي: تنبيه)، صف «الشدة» اختياري، موضع سريع اختياري (سورة/آية — مبدوءة بقيم نطاق الجلسة)، حقل نص حر، والحقول المخصصة إن وجدت. «احفظ الملاحظة» → POST — وعند النجاح: **تسقط خرزة** بلون الفئة على **خيط الجلسة**.
- **خيط الجلسة** (التوقيع البصري): شريط أفقي رفيع أسفل الشاشة يمثل الزمن من 0 إلى الآن، عليه خرزات دائرية صغيرة عند مواضع الملاحظات بألوان فئاتها، وخرزة تسقط بحركة ≤200ms عند الإضافة (تُعطَّل مع reduced-motion). tooltip باللمس الطويل/hover يظهر الفئة والوقت.
- الملاحظة تُحفظ متفائلة (optimistic): الخرزة تظهر فوراً، وعند فشل POST تظهر Toast خطأ ويُعاد فتح اللوحة بمحتواها.
- زر «أنهِ الجلسة» (secondary فوق اللازورد) → حوار تأكيد: ملخص اختياري + تأكيد الحضور، ثم `finalize({summary, attendance})` مع عرض تقدم تصريف المقاطع → عند النجاح انتقال لصفحة تفاصيل الجلسة `/sessions/{id}` مع Toast «تم حفظ الجلسة — الدرجة المقترحة: {suggested_grade}» وإتاحة تعديل الدرجة هناك (PATCH).
- زر «إلغاء» ghost صغير (حوار تأكيد صريح: «سيُحذف تسجيل هذه الجلسة نهائياً»).
- حالات المحرك: `acquiring` شاشة انتظار إذن الميكروفون بتعليمات عربية؛ `error` رسالة `fatalError` مع زر عودة؛ رفض الإذن يشرح كيفية تفعيله.
- الاستئناف: الدخول إلى `/sessions/live` وثمة جلسة نشطة → `start({sessionId, segment: maxSeg+1, priorChunks: مجموع الفهارس, priorUploaded: uploaded})`.
