## الصفحة — `/` (تستبدل placeholder «لوحة التحكم»)

### صف الفلاتر (سطر واحد أعلى الصفحة، يلتف على الموبايل)
- فترات جاهزة كأزرار تبديل: «٧ أيام» «٣٠ يوماً» «٩٠ يوماً» «مخصص» (يكشف حقلي من/إلى). الافتراضي ٣٠.
- Select الحلقة (الكل + القائمة)؛ Select المعلم (admin/supervisor فقط — teacher لا يظهر له لأنه مقيد أصلاً من الخادم)؛ Select نوع الجلسة.
- كل تغيير فلتر يعيد الجلب (react-query بمفتاح يشمل الفلاتر). أثناء الجلب: شفافية خفيفة على المحتوى لا Spinner صفحة كاملة (تجربة أرقى للفلترة).

### صف بطاقات الإحصاء (5 بطاقات)
طلاب نشطون / جلسات الفترة / متوسط الدرجة (مع «من 100» صغيرة) / نسبة الحضور % / إجمالي التلاوة (س:د mono). القيم mono كبيرة (27)، التسمية 13 hibr-2. «—» عند لا بيانات.

### شبكة الرسوم (عمودان على الواسع، عمود على الموبايل)
1. **«الجلسات عبر الفترة»**: BarChartV يومي بلون lazward-700 — **املأ الأيام الناقصة بصفر** على كامل الفترة قبل التمرير للرسم (الخادم لا يرسل أيام الصفر). لو الفترة > 45 يوماً جمّع أسبوعياً (client-side) ليبقى الرسم مقروءاً.
2. **«الأخطاء حسب التصنيف»**: BarChartH بألوان `--chart-*` من `color` لكل فئة (استخدم `lib/noteColors.ts` إن كان يغطي توكنز الرسوم أو وسّعه بأصغر تعديل).
3. **«توزيع الدرجات»**: BarChartV للسلال الأربع بترتيبها (90-100، 80-89، 70-79، أقل من 70) بلون lazward-700.
4. **«بحاجة لعناية»**: ليست رسماً — قائمة صفوف: اسم الطالب (رابط لملفه) + الحلقة + متوسط الدرجة mono ملوّن (أحمر خفيف < 75) + عدد الجلسات. جملة تمهيدية محترمة: «طلاب قد يحتاجون وقتاً إضافياً هذه الفترة». فارغة؟ «لا أحد يحتاج عناية خاصة — أداء طيب عموماً».

### جدول ملخص الحلقات
الحلقة، الطلاب، الجلسات، متوسط الدرجة. صف قابل للنقر → `/students?group_id=`.

### حالات خاصة
- فترة بلا أي جلسات: حالة فارغة أنيقة واحدة تحل محل الشبكة كلها («لا جلسات في هذه الفترة») مع بقاء الفلاتر ظاهرة.
- معلم جديد بلا حلقات: حالة فارغة توجهه: «ابدأ بإنشاء حلقة وإضافة طلابك».
