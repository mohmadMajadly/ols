# شكر وإسناد — بيانات وخطوط المصحف (WP9a)

بيانات مصحف المدينة النبوية وخطوطه المستخدمة في هذا المشروع (نص القرآن الكريم،
تخطيط الصفحات، خطوط QPC V2) مصدرها جهات موثوقة، مجانية الاستخدام مع الإسناد.
هذا الملف إسناد موجز لها:

- **مجمع الملك فهد لطباعة المصحف الشريف** (المدينة المنورة) — الخطوط
  والتصميم الأصلي لصفحات مصحف المدينة (رواية حفص عن عاصم، طبعة 1421هـ، تخطيط
  QPC V2)، وهي الجهة صاحبة العمل الفني لكل حرف وصفحة. المرجع:
  https://qurancomplex.gov.sa

- **Quranic Universal Library — Tarteel (QUL)** — تخطيط الصفحات/الأسطر
  (نوع كل سطر: اسم سورة / بسملة / آيات) بصيغة قاعدة بيانات مفتوحة:
  https://qul.tarteel.ai/resources/mushaf-layout

- **Tanzil Project** — النص العثماني المرجعي للقرآن الكريم، المستخدم للتحقق
  الحرفي من صحة النصوص المُخزَّنة: https://tanzil.net

- **quran.com (Quran.Foundation)** — واجهة برمجية (API v4) لنص كل كلمة ورمز
  حرفها في خط QPC V2 ورقم سطرها، واستضافة إعادة بناء حديثة (OpenType) لخطوط
  مجمع الملك فهد صفحة-بصفحة تعمل بشكل صحيح في المتصفحات: https://quran.com

جميع هذه المصادر تُستخدَم هنا لأغراض تعليمية غير ربحية ضمن مشروع OLS، مع
الحفاظ الكامل على دقة نص القرآن الكريم دون أي تعديل عليه.
