# الاتجاه البصري لمنصة OLS — وثيقة ملزمة لكل عمل واجهات

كاتبها: المدير (Fable). أي وكيل ينفذ UI يلتزم بها حرفياً. أي خروج عنها يحتاج موافقة المدير.

> **تحديث ملزم (2026-08-29، قرار المستخدم):** أُلغي مفهوم «عالم اللازورد الداكن» لشاشة الجلسة — رفضه المستخدم لتنافره مع بقية التطبيق ومع صفحة المصحف الورقية. شاشة الجلسة الآن من **عالم الورق** كسائر الشاشات، وهويتها الخاصة هي **التذهيب**: هالة التلاوة الذهبية والنبض الذهبي على الورق (كزخرفة المخطوطات المذهبة). §1 أدناه تاريخي؛ ما بعده من قواعد (الذهب، الألوان الدلالية، الحركة...) باقٍ كما هو.

## 1. الفكرة الجوهرية: عالمان (مُلغى — انظر التحديث أعلاه)

المنصة أداة عمل يومية لمركز تحفيظ، وفيها لحظة واحدة مقدسة: **جلسة التسميع**. لذلك للتطبيق عالمان بصريان متعمدان:

1. **عالم الإدارة (الورق)** — كل شاشات الإدارة والملفات والإحصائيات: خلفية ورقية فاتحة قريبة من الأبيض، كثافة هادئة، حواف رقيقة، كفاءة مكتبية صارمة. لا زخرفة.
2. **عالم التلاوة (اللازورد)** — شاشة الجلسة الحية فقط: خلفية نيلية عميقة مستوحاة من **المصحف الأزرق القيرواني** (رقّ مصبوغ بالنيلة وكتابة ذهبية — أيقونة حقيقية في تاريخ المصاحف)، تركيز كامل، عناصر قليلة، الذهب فيها وظيفي لا زخرفي. عملياً أيضاً: شاشة داكنة أهدأ داخل الحلقة، وعلامات الأخطاء الحمراء تبرز عليها بوضوح.

الانتقال بين العالمين هو نفسه رسالة: دخلتَ الجلسة = دخلتَ حضرة النص.

## 2. الألوان (Tokens)

```css
:root {
  /* الورق — عالم الإدارة */
  --waraq:        #FAF9F6;  /* خلفية الصفحات — أبيض دافئ بلا صفار */
  --waraq-raised: #FFFFFF;  /* البطاقات والأسطح المرتفعة */
  --hibr:         #1C2333;  /* الحبر — نص أساسي (أسود بميل نيلي) */
  --hibr-2:       #5A6072;  /* نص ثانوي */
  --hibr-3:       #9BA0AE;  /* نص خافت/تعطيل */
  --khatt:        #E4E2DC;  /* حدود hairline 1px */

  /* اللازورد — الهوية والفعل الأساسي */
  --lazward-900:  #141C3F;  /* خلفية عالم التلاوة */
  --lazward-800:  #1D2854;  /* أسطح مرتفعة داخل عالم التلاوة */
  --lazward-700:  #27356E;  /* الأزرار الأساسية، الروابط، التركيز */
  --lazward-100:  #E7EAF4;  /* خلفيات تمييز خفيفة */
  --nur:          #F2EFE7;  /* نص فوق اللازورد — "نور" وليس أبيض صارخ */

  /* الذهب — نادر وثمين: علامات الآي، لحظة التسجيل، الإنجاز فقط */
  --dhahab:       #B08A3E;
  --dhahab-bright:#D4AF5E;  /* نبض التسجيل فوق اللازورد */

  /* دلالات */
  --sahih:        #2F7A52;  /* متقن/نجاح */
  --khata-hifz:   #A93B2E;  /* أخطاء الحفظ (اللحن الجلي) */
  --khata-tajwid: #8A5A00;  /* أخطاء التجويد (اللحن الخفي) — كهرماني عميق */
  --khata-dabt:   #6B4A8E;  /* الضبط والتشكيل — بنفسجي هادئ */
  --waqf:         #33667A;  /* الوقف والابتداء — أزرق بترولي */
}
```

### ألوان الرسوم البيانية (مدققة آلياً بمدقق dataviz — CVD وتباين وإشباع، كلها PASS)

```css
:root {
  /* نسخ الرسوم من الألوان الدلالية — للسلاسل في المخططات حصراً.
     اللون يتبع الفئة أينما ظهرت، بترتيب عرض ثابت: حفظ، تجويد، ضبط، وقف، إتقان */
  --chart-hifz:   #A93B2E;
  --chart-tajwid: #B58312;
  --chart-dabt:   #5E3D85;
  --chart-waqf:   #2E8FB8;
  --chart-sahih:  #257A47;
}
```
قواعد الرسوم: محور واحد دائماً (لا محورين y)؛ سلسلة واحدة = لون lazward-700 بلا legend؛ ≥2 سلاسل = legend دائماً؛ علامات رفيعة بفواصل 2px؛ tooltips عند المرور إلزامية؛ الشبكة خافتة؛ النصوص بألوان الحبر لا بلون السلسلة.

قواعد: الذهب لا يُستخدم في الحدود ولا الخلفيات العامة أبداً — فقط: دائرة نبض التسجيل، علامات مواضع الآي، شارات الإتقان. الأحمر محجوز للأخطاء حصراً (لا أزرار حذف حمراء كبيرة — الحذف رمادي بحوار تأكيد). ألوان الرسوم البيانية تُشتق لاحقاً من ألوان التصنيفات أعلاه وفق سكيل dataviz.

## 3. الخطوط

| الدور | الخط | الاستخدام |
|---|---|---|
| العرض (Display) | **Amiri** (700) | عناوين الصفحات وأسماء الطلاب في الترويسات فقط — نسخي أصيل من تقليد مطبعة بولاق، يعطي روح المخطوطة بلا زخرفة |
| الواجهة (Body/UI) | **IBM Plex Sans Arabic** (400/500/600) | كل شيء آخر: نصوص، أزرار، جداول، نماذج |
| نص القرآن | **KFGQPC HAFS** (لاحقاً خطوط QPC للصفحات) | الآيات حصراً — لا يُستخدم لغيرها أبداً، ولا يُعرض القرآن بغيرها أبداً |
| الأرقام الزمنية | IBM Plex Mono | الطوابع الزمنية 04:32 وأرقام العدادات — أرقام لاتينية بعرض ثابت |

- الخطوط **مستضافة ذاتياً** (woff2 داخل المشروع) — لا Google Fonts CDN (سيرفر عام + خصوصية + سرعة).
- سلم الحجم: 13 / 15 (الأساس) / 17 / 21 / 27 / 34. الأوزان: لا Bold للنص العادي؛ التمييز بالوزن 600 وبالمقام اللوني.
- الأرقام في الجداول والإحصاءات: tabular-nums.

## 4. الشكل والبنية

- RTL كامل؛ الشريط الجانبي على **اليمين** (بداية القراءة)، قابل للطي.
- شبكة 8px؛ هوامش صفحات سخية (24–32px).
- الحواف: radius **8px** للبطاقات، 6px للأزرار والحقول — لا حواف منتفخة 16px+ (مظهر القوالب).
- الحدود: 1px بلون `--khatt`؛ الظلال شبه معدومة (ظل واحد خفيف للعناصر العائمة فقط). العمق يُبنى بالحدود والمقامات اللونية لا بالظلال.
- البطاقات لا تُستخدم لكل شيء: الجداول جداول حقيقية بصفوف مفصولة بخطوط رقيقة (روح السجل/الكشف الورقي للمعلم، لكن منضبطة).
- **رقاقة الموضع القرآني**: كل إشارة (سورة: آية) تُعرض داخل شكل مستدير مستوحى من علامة رأس الآية ۝ — حدها ذهبي رفيع، هذا هو الموضع الوحيد الزخرفي في عالم الإدارة، ويحمل معنى حقيقياً (موضع قرآني).

## 5. التوقيع البصري: خيط الجلسة

العنصر الذي تُذكر به المنصة: **الشكل الموجي للتسجيل وعليه الملاحظات كخرزات**. الملاحظات الموقوتة تظهر على الموجة كدوائر صغيرة ملونة بلون تصنيفها — كخرزات مسبحة على خيط. النقر على خرزة يقفز بالصوت إليها (قبلها بـ5 ثوانٍ). في لحظة الضغط على زر ملاحظة أثناء الجلسة، تسقط الخرزة على الخيط فوراً (حركة قصيرة ≤200ms) — تأكيد بصري أن اللحظة قُيّدت ولو لم تكتمل الكتابة.

## 6. الحركة

قليلة ومقصودة: نبض ذهبي بطيء حول مؤشر التسجيل (تنفس ~2s)، سقوط الخرزة، انتقالات شفافية/إزاحة ≤200ms. لا parallax، لا confetti، لا حركات ترحيبية. `prefers-reduced-motion` محترم دائماً (يوقف النبض والسقوط).

## 7. الصوت اللغوي للواجهة

- عربية فصيحة مختصرة محترمة تليق بسياق القرآن. لا علامات تعجب، لا حماسة تسويقية، لا "رائع!".
- الأزرار أفعال أمر واضحة: «ابدأ التسميع»، «أنهِ الجلسة»، «احفظ الملاحظة». الفعل يحتفظ باسمه في كل الرحلة.
- المصطلحات الشرعية الصحيحة كما هي: سبق، سبقيات، مراجعة كبرى، لحن جلي، لحن خفي، الفتح على الطالب.
- الأخطاء توجيهية محددة: ماذا حدث وكيف يُصلح. الشاشات الفارغة دعوة للفعل: «لا طلاب بعد — أضف أول طالب».
- التاريخ هجري وميلادي معاً حيث يظهر التاريخ.

## 8. خط الجودة الأدنى (بلا نقاش)

متجاوب حتى 360px (المعلم قد يستخدم جوالاً في الحلقة)؛ تركيز لوحة مفاتيح مرئي (حلقة `--lazward-700`)؛ تباين AA على الأقل لكل نص؛ لمسات هدف ≥44px في شاشة الجلسة (تُستخدم واقفاً وبسرعة)؛ RTL سليم في كل مكون (لا أسهم بالاتجاه الخطأ).

## 9. ممنوعات (تلخّص كل ما سبق)

خلفية كريمية غامقة + تيراكوتا؛ داكن + أخضر حمضي؛ Cairo/Tajawal كخط رئيسي؛ مكتبات UI جاهزة (shadcn/MUI/Ant)؛ أيقونات ملونة متعددة الألوان؛ إيموجي في الواجهة؛ تدرجات لونية في الأزرار؛ ظلال ثقيلة؛ زوايا 16px+؛ الذهب كلون عام؛ عرض نص قرآني بخط غير قرآني.
